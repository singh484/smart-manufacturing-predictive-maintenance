🏭 Smart Manufacturing Predictive MaintenanceIndustrial IoT (IIoT) Telemetry Analytics, Health Scoring & Failure Forecasting PlatformTransforming raw factory floor sensor streams into actionable maintenance intelligence—minimizing unplanned downtime, extending equipment lifespan, and optimizing operational efficiency.📖 Executive OverviewUnplanned equipment downtime is one of the highest operational costs in modern manufacturing. Traditional reactive maintenance (fixing machines after they break) leads to costly production halts, while preventive maintenance (servicing on rigid schedules) often wastes viable component life.Smart Manufacturing Predictive Maintenance bridges this gap by combining Industrial IoT (IIoT) telemetry with Supervised Machine Learning inside an interactive Streamlit web application. Designed for reliability engineers, plant managers, and data scientists, the platform ingests multi-sensor equipment logs, uncovers early degradation patterns, and calculates real-time failure probabilities and Asset Health Indices.🚀 Core Capabilities (Category-Wise Breakdown)1. 📂 Data Ingestion & Schema ValidationSeamless CSV Upload: Drag-and-drop custom industrial sensor logs directly into the web interface without writing a single line of code.Built-In Synthetic Telemetry Engine: Automatically generates realistic multi-machine IIoT datasets (simulating ambient/process temperatures, rotational speeds, torque loads, and progressive tool wear) so you can explore and benchmark the platform immediately upon launch.Automated Preprocessing: Dynamically separates numerical and categorical features, handles missing values, and validates target schema integrity prior to model execution.2. 📊 Exploratory Data Analysis (EDA) & Telemetry InsightsFleet-Level KPIs: Instant visibility into total logged telemetry cycles, historical failure rates, and total active machines under supervision.Distribution & Anomaly Profiling: Interactive, overlaid histograms comparing healthy operating baselines against failure-state sensor distributions to pinpoint critical operating thresholds.Tabular Data Inspector: Clean, scrollable data previews for rapid auditing of raw sensor streams.3. 🤖 Machine Learning & Failure Prediction EngineEnd-to-End Scikit-Learn Pipeline: Encapsulates feature scaling (StandardScaler), categorical encoding (OneHotEncoder), and ensemble classification (RandomForestClassifier) to prevent data leakage and ensure reproducible inference.Transparent Model Evaluation: Automatically evaluates model generalization on hold-out test splits using Accuracy, F1-Score (crucial for imbalanced failure events), and ROC-AUC.Interactive "What-If" Asset Simulator: Adjust real-time sensor sliders (e.g., increasing torque or cumulative tool wear) to simulate stress scenarios and observe immediate shifts in predicted failure probability.4. 🩺 Machine Health Monitoring & Asset DiagnosticsContinuous Health Index ($0\text{–}100$): Translates raw model failure probabilities into an intuitive equipment health score:
$$\text{Health Index} = (1 - P_{\text{failure}}) \times 100$$Asset-Specific Drilldowns: Filter telemetry history by individual machine_id to inspect degradation trajectories over time.Multi-Axis Trend Visualization: Interactive Plotly line charts overlay asset Health Index curves alongside key physical telemetry (such as temperature and rotational speed) to correlate physical wear with declining health.🏗️ System Architecture & Workflow┌──────────────────────┐     ┌─────────────────────────┐     ┌──────────────────────────┐
